# Provenance

ReqContext was developed with AI assistance from the project requirements.
Implementation files were not imported from Aider, Continue or CodeGraph. Their
documentation informed comparisons; overlap in general techniques is expected.

## Dependencies

| Dependency | Optional use |
|---|---|
| Tree-sitter and tree-sitter-c | C parsing |
| pypdf | PDF text extraction |
| MCP Python SDK | Stdio server/client protocol |

These dependencies are installed separately and are governed by their respective
licenses. The Python AST parser and SQLite access use the standard library.

## Repository content

Examples are small project fixtures. Historical audit transcripts, third-party
source excerpts, benchmark output and cloned evaluation repositories are not part
of this source tree. No production adoption or independently established model
accuracy is claimed. The project license remains an owner decision.
